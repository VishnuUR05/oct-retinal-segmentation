PROJECT PROGRESS REPORT: OCT SEGMENTATION & STRUCTURAL FEATURE EXTRACTION
================================================================================

1. PROJECT OBJECTIVE & ALIGNMENT
--------------------------------------------------------------------------------
Objective: To build a robust, leakage-free deep learning pipeline capable of segmenting 512x512 Optical Coherence Tomography (OCT) B-scans and mathematically extracting "quantitative retinal structural features" (layer thicknesses). 

Importance: The retina is an extension of the central nervous system. Non-invasive OCT imaging allows us to measure retinal layer thickness with micrometer precision. By building a highly accurate segmentation model, we establish the foundational measurements required to later investigate whether structural retinal changes act as biomarkers for neurodegenerative diseases such as Alzheimer's Disease (AD) and Mild Cognitive Impairment (MCI). 

Current Status: We have successfully completed dataset preparation, model training, rigorous mathematical validation, and developed an interactive demonstration application.

2. DATASET COLLECTION & SOURCING
--------------------------------------------------------------------------------
Dataset: OCT5k (specifically the manual grading subset).
Composition: 1,672 manual OCT images and 5,016 manual masks (annotated by three independent graders: Grading_1, Grading_2, Grading_3), along with ground-truth coordinate boundaries in CSV format.

How it was downloaded: The project utilized a Python script (`Scripts/download_images_windows.py`) to systematically fetch and unpack the dataset into local directories. The code works by establishing connections to the data hosting source, downloading compressed archives or individual files, and structuring them into `Images/Images_Manual`, `Masks/Masks_Manual`, and `Boundaries/Boundaries_Manual` to ensure file path symmetry.

3. DATASET PREPROCESSING & LEAKAGE PREVENTION
--------------------------------------------------------------------------------
A critical early discovery was that the 1,672 OCT B-scans originated from only 60 unique patient examination sessions (known as "E2E groups"). 

Action Taken: If we had randomly split the images, scans from the same patient would have ended up in both the training and testing sets, causing "data leakage" (artificially inflating model accuracy). 
We wrote a custom Python script (`create_splits.py`) to enforce a strict Group-K-Fold logic based on the E2E session identifier.

Final Split Ratio:
- Training: 41 E2E Groups (1,102 images) ~ 70%
- Validation: 10 E2E Groups (274 images) ~ 15%
- Testing: 9 E2E Groups (296 images) ~ 15%

Data Preprocessing: Using the `Albumentations` library, all 1-channel grayscale OCT images were duplicated into 3-channels to satisfy standard pre-trained neural networks. The images were normalized using standard ImageNet statistics (Mean: 0.485, 0.456, 0.406 | Std: 0.229, 0.224, 0.225). During training, we applied `A.Affine` transformations (rotation, scaling, translation) to improve model generalization.

4. MODEL ARCHITECTURE
--------------------------------------------------------------------------------
Model: U-Net
Encoder (Backbone): ResNet34 (Residual Network with 34 layers).

How it works: U-Net is a Fully Convolutional Network (FCN) consisting of a contracting path (encoder) that captures context, and an expanding path (decoder) that enables precise pixel-level localization. ResNet34 is used as the encoder and initialized with weights pre-trained on the ImageNet dataset, granting the model a head-start in recognizing foundational visual features (edges, textures).

Output Classes (6 anatomical layers):
0 = Background above ILM
1 = ILM to OPL (Inner Limiting Membrane to Outer Plexiform Layer)
2 = OPL to IS-OS (Outer Plexiform Layer to Inner Segment/Outer Segment junction)
3 = IS-OS to IBRPE (IS-OS to Inner Boundary of Retinal Pigment Epithelium)
4 = IBRPE to OBRPE (Inner to Outer Boundary of RPE)
5 = Background below OBRPE

5. TRAINING CONFIGURATION
--------------------------------------------------------------------------------
Hardware: NVIDIA RTX 3050 (6GB VRAM) laptop GPU.
Batch Size: 4 (Determined optimally via a diagnostic dry run to utilize ~1.16GB VRAM).
Loss Function: Cross-Entropy Loss + Dice Loss. (Cross-Entropy penalizes pixel-wise classification errors, while Dice Loss optimizes the intersection-over-union metric, which is excellent for handling class imbalance).
Optimizer: AdamW (Learning Rate = 1e-4).
Precision: PyTorch Automatic Mixed Precision (AMP / autocast) was utilized to speed up training and reduce memory footprint.
Scheduler: `ReduceLROnPlateau` — reduced learning rate by a factor of 0.5 if the Validation Foreground Dice did not improve for 5 epochs.
Early Stopping: Halted training after 10 epochs of no improvement.
Reproducibility: Seed permanently fixed to 42.

6. RESULTS & EVALUATION
--------------------------------------------------------------------------------
The trained model (`outputs/checkpoints/best_model.pth`) was evaluated on the completely unseen Test Set (296 images).

Segmentation Metrics:
- Mean Dice Coefficient (All Classes): 94.33%
- Mean Foreground Dice (Classes 1-5): 93.27%
- Mean Intersection over Union (IoU): 90.42%

Boundary Extraction & Structural Features:
We wrote `src/extract_boundaries.py` to convert the predicted 6-class mask into 5 distinct mathematical boundary curves (ILM, OPL, IS-OS, IBRPE, OBRPE) by detecting class transition pixels. 

During this, we discovered an anomaly in the human-annotated Ground Truth (GT): In some diseased retinas (e.g., Diabetic Macular Edema / DME), the human graders accidentally drew the photoreceptor layer (IS-OS) physically dipping below the RPE layer (IBRPE) by 1-2 pixels, which is anatomically impossible. 
Our script was designed to robustly detect these missing classes, mark them as NaN (invalid), and use Pandas Linear Interpolation to accurately reconstruct the continuous topological profile.

Boundary Accuracy (Mean Absolute Error vs Ground Truth in Pixels):
- ILM: 1.07 px error
- OPL: 1.67 px error
- IS-OS: 0.70 px error
- IBRPE: 1.00 px error
- Total Retinal Thickness: 1.31 px error

Conclusion: The model is exceptionally accurate, predicting retinal thickness to within 1-2 pixels of a human grader.

7. INTERACTIVE DEMONSTRATION
--------------------------------------------------------------------------------
To prove the pipeline's effectiveness, we built a local Streamlit web application (`app.py`). 
By running `streamlit run app.py`, a user can upload a raw OCT scan in their web browser. The application runs a live inference pass using the RTX 3050 GPU, automatically generating the segmentation mask, rendering an overlay of the boundary curves, and computing a table of the structural thickness features (both global and central-window averages).
